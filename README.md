# Namasvi Patil — Portfolio Website

A responsive multi-page student portfolio with a dark creative-studio aesthetic, neon lime accents, CSS project illustrations, mobile navigation, and a mail-app contact form.

## Pages
- `index.html` — Home and introduction
- `projects.html` — Three academic projects
- `skills.html` — Technical and soft skills
- `contact.html` — Contact details and email-draft form

## Run locally
Open `index.html` in a browser, or use the Live Server extension in VS Code.

## Important customization
1. In `contact.html`, replace `your.email@example.com` with your real email address.
2. Replace GitHub and LinkedIn links with your own profiles.
3. Add your actual project repository links after publishing them.
4. Update skill levels to accurately reflect your experience.
5. Replace the included sample resume with your final resume if needed.

## Publish with GitHub Pages
Upload the extracted files to a public GitHub repository, keeping `index.html` at the repository root. In Settings → Pages, deploy from branch `main` and folder `/(root)`.
